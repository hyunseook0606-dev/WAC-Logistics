# Validation & metrics (portfolio)

실무 문서 1건 + 월간 마스터 1건으로 **구조를 검증**한 기록입니다.  
회사 전체 업무 시간 절감 %는 측정하지 않았고, 포폴에도 그렇게 쓰지 않습니다.

**Sources (local internship materials, not in repo)**  
- `cost item_origin.xlsx` — HK EXP local master (Mar 2026 validity pattern)  
- `INV_AE260703101.pdf` — real HK origin bill (sample lane ~84 kg C.W., FX 7.8)

**Live demo:** https://wac-logistics.vercel.app

## 1. What we measured

| Metric | Result | Meaning |
|--------|--------|---------|
| INV charge lines (ex-air) | **7** | Handling, CFS, Terminal, Document, Cartage, Tunnel, Parking |
| Exact master match | **2 / 7 (29%)** | Terminal Flat×C.W., Document Min |
| Master structure, rate differs | **2 / 7 (29%)** | Handling, CFS — formula exists, amount not 1:1 |
| Not on Excel master | **3 / 7 (43%)** | Cartage, Tunnel, Parking → **Desk variable slots** |
| Auto local lines in MVP | **4** always-on + **4** optional checkboxes | Terminal, Document, Handling, CFS / X-ray, ULD, DG, WH Reg |
| Paste outputs | **2** | Public `Copy Email Draft` vs Desk `Copy Cost Sheet` |

**Takeaway:** 같은 건이라도 엑셀 마스터만으로는 Formal INV를 재현할 수 없고, **건별 변동비(약 40%+)는 사람 입력이 필요**하다.

## 2. Line-by-line: master vs INV (84 kg C.W.)

| INV line | Excel / master | Desk behavior | Check |
|----------|----------------|---------------|-------|
| AIR FREIGHT FEE | Air (USD) → × FX | Air line + FX (default 7.8) | Structure OK; rate source is mock / desk-selected |
| TERMINAL CHARGE | Flat 1.68/kg | `max(60, 1.68×C.W.)` → 84×1.68 | **Match** |
| DOCUMENT FEE | Min 15 / job | per-job 15 | **Match** |
| CFS CHARGE | Min 160, Flat 1.2 | `max(160, 1.2×C.W.)` | Structure OK; INV used Min path |
| HANDLING CHARGE | Excel Min **150** | per-job 150 | **Gap** — INV showed **312** (account/contract?) |
| CARTAGE | Not on master | Variable slot (sample default 650) | Per-job |
| TUNNEL FEE | Not on master | Variable slot (sample default 16) | Per-job |
| PARKING FEE | Not on master | Variable slot (sample default 15) | Per-job |

Formula used for per-kg master lines:

```text
amount = max(Min, Flat × C.W.)
C.W.   = max(gross kg, L×W×H / 6000)
```

## 3. Product split (why two modes)

| | Public Quote | WAC Desk |
|--|--------------|----------|
| Audience | Shipper / nominee | Internal desk |
| Inputs | Lane + dims + weight | Same + variable slots + optional flags + FX |
| Output | Indicative **air** USD + email draft | Formal origin cost sheet HKD/USD |
| Does not do | Cartage / tunnel / parking | Claim “final invoice without review” |

This matches how large forwarders separate **instant indicative** from **final chargeable cost**.

---

## 4. Limits (intentional)

- Air rates remain **mock** (no CargoAI / internal rate DB in this MVP).  
- Variable defaults are from **one** sample INV — desk must edit every job.  
- Handling gap (150 vs 312) was left visible on purpose: proves full automation is unsafe without account rules / SOP.  
- Internship feedback redirected next work to **cost/profit understanding, quote→INV data linkage, SOP**, and **W EXPRESS** improvement — not further custom system build.

---

## 5. Portfolio one-liner

> Validated HK origin cost structure against a live master + real INV: ~43% of non-air lines were job-variable (Cartage/Tunnel/Parking), so the MVP separates monthly master auto-calc from desk slots and ships Public vs Desk paste workflows — without claiming end-to-end invoice automation.
